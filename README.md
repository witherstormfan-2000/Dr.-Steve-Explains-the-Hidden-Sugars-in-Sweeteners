# Beyond Zero — Sweetener Label Guide

A simple static website explaining dextrose, maltodextrin, and carbohydrate labeling, with a Dr. Steve illustration.

## Publish with GitHub Pages

1. Upload **index.html** and **dr-steve.png** to the root of your GitHub repository (and this README if desired).
2. Replace the older versions of any files with matching names.
3. Go to Settings → Pages → Deploy from a branch → main → / (root), then Save.
4. Wait for GitHub Pages to deploy.

All files must be at the repository root so the image loads correctly. The website includes links to the four official Splenda product pages but no `.edu` links.

This site is independent educational content, not medical advice.
